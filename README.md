# Benchtick (가칭) — 실험실 올인원 벤치 도구 (Flutter)

실험 중 벤치 옆에 두고 쓰는 타이머·플레이트 추적·셀 카운트·시약 계산·프로토콜 기록 앱.
서버 없이 전부 기기 로컬에 저장되며, 안드로이드/윈도우 양쪽에서 같은 코드로 빌드됩니다.

> 이름은 아직 가칭입니다. 후보였던 BenchMate / LabBench / WellDone / LabJAM / Pipetto는
> 기존 상표·앱과 겹쳐서 제외했고, Benchtick과 Assaynojam은 겹치는 게 없어 후보로 남아있어요.
> 정식 배포 전엔 키프리스(KIPRIS)에서 한 번 더 공식 확인을 권장합니다.

## 탭 구성 (사용 빈도 순)

**타이머 → 플레이트 → 셀카운트 → 시약계산 → 프로토콜**

---

## 1. 타이머 (T1~T4 4채널)
- 상단 탭으로 채널 전환. 채널을 바꿔도 다른 채널은 백그라운드에서 계속 흐름 (실물 4채널 타이머와 동일한 동작).
- 시작 버튼만 누르면 스탑워치(카운트업). 숫자를 탭하면 시간 설정 창이 열리고, 시간을 설정하면 타이머(카운트다운)로 전환.
- **목표 시간을 넘겨도 정지하지 않고 마이너스로 계속 흐름** (`-05:23`처럼 표시) — 과학자가 얼마나 초과됐는지 계속 확인 가능. 0을 넘는 순간 알림음·진동은 한 번만 울리고, 화면은 초과되는 동안 계속 빨간색으로 강조됩니다.
- 화면 최상단에 현재 시각 실시간 표시.
- 큰 글씨(다크 배경 + 초록/흰색 숫자)로 가시성 확보. 실행 중엔 초록, 초과 시엔 빨강.
- 각 채널 값은 앱을 껐다 켜도 유지 (재실행 시 실행 상태만 항상 정지로 안전하게 불러옴).

## 2. 플레이트 분주 위치 추적
- 6 / 12 / 24 / 48 / 96 / 384 Well 드롭다운으로 선택.
- 칸을 탭하거나, 손가락으로 쭉 드래그하면 지나가는 칸이 연속으로 선택/해제됨 (첫 칸이 비어있었으면 드래그 내내 "선택", 이미 선택돼 있었으면 드래그 내내 "해제").
- 화면 크기·플레이트 종류에 관계없이 그리드가 항상 화면 안에 다 들어오도록 셀 크기를 가로/세로 각각 계산해서 렌더링.
- 진행 상황은 플레이트 종류별로 각각 로컬 저장 → 실험 중간에 앱이 꺼지거나 다른 플레이트로 바꿔도 이어서 확인 가능.
- 우측 상단 "초기화"로 전체 리셋 (확인창 있음).

## 3. 셀 카운트
- "탭하여 카운트 +1" 버튼을 누를 때마다 숫자가 올라감, "초기화"로 리셋.
- "계산하기"를 누르는 순간 카운트가 고정되고 계산 화면으로 전환, 상단에 방금 센 숫자가 표시됨.
- **현재 세포 농도**: 계산한 칸 수 + 희석배수 입력 → 혈구계산판 표준 공식(칸당 평균 세포수 × 희석배수 × 10⁴)으로 cells/mL 계산. 기본값(4칸, 희석배수 2)은 트립판블루 표준 카운팅 기준이니 실험실 SOP와 다르면 값을 바꿔서 쓰면 됩니다.
- **목표 농도로 희석**: 목표 농도 + 목표 최종 부피 입력 → 필요한 현탁액 부피 + 추가할 배지량 계산 (C1V1=C2V2 방식).

## 4. 시약 제조 계산기
세 가지 모드를 칩(chip)으로 전환, 입력하는 즉시 결과 갱신 (버튼 필요 없음):
- **몰농도→질량**: 목표 몰농도(M/mM/µM/nM) + 부피(L/mL/µL) + 분자량(g/mol) → 필요한 질량(g/mg/µg)
- **희석 계산 (C1V1=C2V2)**: 원액 농도 + 목표 농도 + 최종 부피 → 원액 필요량 + 추가할 용매량
- **%농도(w/v)→질량**: 목표 %(g/100mL 기준) + 부피 → 필요한 질량

## 5. 프로토콜 기록
- **작성**: 프로토콜 이름 + 절차(기본 5칸, 15개까지 추가 가능) 직접 입력.
- **저장/불러오기**: 목록에서 저장된 프로토콜을 눌러 바로 실행, 우측 점 3개 메뉴로 수정/삭제.
- **실행**: 절차 옆 칸을 탭하면 체크되고 완료 시각이 자동 기록 (다시 탭하면 취소).
- **Gmail 공유**: 실행 화면 우측 상단 공유 아이콘 → 완료 여부/시각이 포함된 텍스트로 메일 작성 화면이 열림.
  - ⚠️ mailto: 방식이라 **기기에 기본 메일 앱이 설정되어 있어야** 동작합니다. 안드로이드는 Gmail이 자연스럽게 열리지만, 윈도우 PC는 보통 기본 메일 앱이 없어 사실상 안드로이드 전용 기능입니다.

## 빌드 방법 (본인 PC에서)

1. Flutter SDK 설치: https://docs.flutter.dev/get-started/install
2. 이 폴더(`lab_timer_app`)를 원하는 위치에 두고 터미널에서:
   ```
   cd lab_timer_app
   flutter pub get
   ```
3. **안드로이드 빌드**
   ```
   flutter build apk --release
   ```
   → `build/app/outputs/flutter-apk/app-release.apk` 파일을 폰에 옮겨 설치.
   (안드로이드 폴더가 없다면 먼저 `flutter create --platforms=android .` 실행 후 다시 진행)

4. **윈도우(PC) 빌드**
   ```
   flutter config --enable-windows-desktop
   flutter create --platforms=windows .
   flutter build windows --release
   ```
   → `build/windows/x64/runner/Release/` 폴더 안의 실행 파일 사용.

> 현재 버전은 **PC 앱과 안드로이드 앱이 각각 독립적으로 동작**합니다 (같은 코드로 양쪽에 설치되는 형태이며, 값 실시간 동기화는 안 됨). 실시간 동기화가 필요하면 Firebase Realtime Database 같은 백엔드를 추가로 붙이는 게 다음 단계로 가능합니다.

## 성능 최적화 메모
- **타이머**: 채널이 하나도 실행 중이 아닐 땐 0.1초가 아니라 1초에 한 번만 화면을 갱신하도록 처리 → 대기 상태에서의 배터리 소모를 크게 줄임. 뭔가 실행 중이면 예전처럼 0.1초 정밀도 유지.
- **플레이트**: 선택 상태(`marked`)를 `ValueNotifier`로 분리해서, 드래그하는 동안 그리드와 상단 카운트 텍스트만 다시 그려지고 나머지 화면(드롭다운 등)은 리빌드되지 않도록 처리 → 384-well처럼 칸이 많은 플레이트에서도 드래그가 매끄럽게 동작.
