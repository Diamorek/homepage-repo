# homepage-repo
# 실험실 4채널 스탑워치/타이머 (Flutter)

## 기능 요약
- **T1~T4 채널**: 상단 탭으로 전환. 채널을 바꿔도 이전 채널은 계속 시간이 흐름 (2530류 4채널 타이머와 동일한 동작).
- **스탑워치 / 타이머 겸용**: 그냥 시작 버튼을 누르면 스탑워치(카운트업). 화면을 길게 누르면 시간 설정 다이얼로그가 뜨고, 시간을 설정하면 타이머(카운트다운)로 동작.
- **현재 시각**: 화면 최상단에 실시간 표시.
- **가시성**: 메인 숫자는 화면 대부분을 차지하는 큰 글씨(다크 배경 + 밝은 녹색/흰색 숫자), 실행 중일 땐 초록색, 타이머 종료 시 빨간색으로 강조.
- **메모리 기능**: 각 채널 값은 앱을 껐다 켜도 유지됨 (SharedPreferences 로컬 저장). 단, 재실행 시 실행 상태는 항상 정지로 불러와 안전하게 시작.
- **타이머 종료 알림**: 시스템 알림음 + 진동.

## 빌드 방법 (본인 PC에서)

1. Flutter SDK 설치: https://docs.flutter.dev/get-started/install
2. 이 폴더(`lab_timer_app`)를 원하는 위치에 그대로 두고 터미널에서:
   ```
   cd lab_timer_app
   flutter pub get
   ```
3. **안드로이드 빌드**
   ```
   flutter build apk --release
   ```
   → `build/app/outputs/flutter-apk/app-release.apk` 파일을 폰에 옮겨 설치하면 됩니다.
   (안드로이드 폴더가 없다면 먼저 `flutter create --platforms=android .` 실행 후 위 코드 다시 진행)

4. **윈도우(PC) 빌드**
   ```
   flutter config --enable-windows-desktop
   flutter create --platforms=windows .
   flutter build windows --release
   ```
   → `build/windows/x64/runner/Release/` 폴더 안의 실행 파일을 그대로 사용하시면 됩니다.

## Plate 분주 위치 추적 (2번째 탭)
- 하단 탭에서 "플레이트"로 전환
- 6/12/24/48/96/384 Well 중 드롭다운으로 선택
- 칸을 탭하거나, 손가락으로 쭉 드래그하면 지나가는 칸이 연속으로 선택/해제됨 (첫 칸이 원래 비어있었으면 드래그 내내 "선택"으로, 이미 선택된 칸이었으면 드래그 내내 "해제"로 동작)
- 진행 상황은 플레이트 종류별로 각각 로컬 저장됨 → 실험 중간에 앱이 꺼지거나 다른 플레이트로 바꿔도 이어서 확인 가능
- 우측 상단 "초기화"로 전체 리셋 (확인 창 뜸)

## 시약 제조 계산기 (3번째 탭)
- **몰농도→질량**: 목표 몰농도(M/mM/µM/nM) + 부피(L/mL/µL) + 분자량(g/mol) → 필요한 질량(g/mg/µg)
- **희석 계산 (C1V1=C2V2)**: 원액 농도 + 목표 농도 + 최종 부피 → 원액 필요량 + 추가할 용매량
- **%농도(w/v)→질량**: 목표 %(g/100mL 기준) + 부피 → 필요한 질량
- 입력하는 즉시 결과가 갱신됩니다 (버튼 누를 필요 없음)
